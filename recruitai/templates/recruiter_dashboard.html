🆓 Browser TTS (current): Completely free. Uses your device's built-in speech engine. Quality varies by OS & browser.
💎 Google Cloud TTS: ~$4/1M characters. High-quality WaveNet voices. Requires API key.
💎 AWS Polly: ~$4/1M characters. Neural voices available. Requires AWS credentials.
💎 ElevenLabs: From $5/mo. Most realistic AI voices. Best for premium experience.

⚙️ Round Setup
How rounds work: Candidates complete rounds in order. Each round can use a different interview mode. After completing a round, candidates are automatically blocked from re-entering it. They must meet the pass threshold to unlock the next round (or you can manually unlock it).
📋 Candidate Round Blocking Rules
🔒 Auto-blocked: After completing any round, candidates cannot re-enter that round
🔓 Auto-unlock: Next round unlocks only when pass threshold is met
⚡ Manual override: You can unlock any round for a candidate from the Applicants page
⏳ Cooldown: Failing all rounds triggers a 60-day global application ban
